# Zephyr interactive saved demo

GitHub Pages artifact for ASH1998/zephyr.

This branch contains the compiled frontend, selected completed NVIDIA DoMINO results, saved Nemotron answers, and licensed car/aircraft assets. No server, API key, model checkpoint or `.env` is needed.

Select a saved session to compare designs, or use the geometry picker to explore the car and aircraft catalog. New inference and uploads run in the full local app.

Generated with `scripts/package-sedan-demo.py` followed by `scripts/package-pages-demo.py` in the application source.
